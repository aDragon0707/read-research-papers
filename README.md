# Read Research Papers

A Codex skill that applies S. Keshav's three-pass method to research papers and exploratory literature surveys.

## What it does

- Screens a paper with a first-pass overview and the five Cs.
- Builds a more detailed claim-and-evidence map in the second pass.
- Guides deep reconstruction in the third pass.
- Supports iterative citation chaining for exploratory literature surveys.

## Install

Copy `SKILL.md` into your Codex skills directory, for example:

```text
~/.codex/skills/read-research-papers/SKILL.md
```

The skill intentionally preserves the original three-pass method as a compact baseline.
